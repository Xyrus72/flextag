# 📬 Learn OTP — How Email Verification Works

Welcome! This folder explains how the OTP (One-Time Password) system works
in **super simple** terms. No experience needed.

---

## 📁 What's in this folder?

```
learn-otp/
│
├── README.md              ← You are here! Start here.
│
├── 1_what_is_otp.md       ← What is an OTP and why do we use it?
├── 2_how_it_works.md      ← Step-by-step: what happens when you register
├── 3_the_code_explained/
│   ├── otp_store.js       ← Simple demo: how the OTP is stored in memory
│   ├── send_email.js      ← Simple demo: how the email is sent
│   └── verify_otp.js      ← Simple demo: how the OTP is checked
│
└── 4_run_it_yourself.md   ← Try it yourself with one command!
```

---

## 🚀 Quick Start

Just read the files in order:

1. Start with `1_what_is_otp.md` to understand the concept
2. Read `2_how_it_works.md` to see the full flow
3. Look at the code examples in `3_the_code_explained/`
4. Try running it yourself with `4_run_it_yourself.md`
